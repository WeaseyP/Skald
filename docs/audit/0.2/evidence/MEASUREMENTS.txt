Key derived facts:
 - Centre Panner = 0.7071x (-3.01 dB) vs no Panner. Confirms F-A08-3.
 - Panner mono downmix (what ANY downstream node reads) = 1.0 at pan 0 and 0.7071 at pan +-1.
   So a Panner mid-chain is a 0..-3 dB volume knob labelled "pan", and it is 3 dB LOUDER than
   the same Panner wired straight to Output. Adding a Filter after a Panner RAISES level 3 dB.
 - Mixer at unity levels == bare wire merge. No headroom/compensation at all.
 - Distortion soft at drive=1 mix=1 -> 0.7616 (tanh(1)); no makeup gain, so the "neutral"
   setting attenuates 2.4 dB. Default drive 20 mix 0.5 raises a 0.525 peak to 0.707 (+2.6 dB).
 - Voice summing is 1:1 unattenuated: 8 identical notes -> exactly 8.0x.
 - Per-asset _process has NO limiter. tanh lives only in project_process, which the repo's own
   integration README tells games not to use.
